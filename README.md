# OpenEarable – Parkour Game

[OpenEarable](https://open-earable.teco.edu) is an open-source, Arduino-based platform for ear-centered sensing applications. It offers a versatile prototyping environment with support for various sensors and actuators, making it ideal for earable research and development.

This project is a **2D jump-and-run platformer** where gameplay is influenced by **sensor data from the OpenEarable device**. Players navigate through obstacles and platforms, while real-time sensor input affects movement, interaction, or gameplay dynamics.

The game explores how wearable sensor data can be meaningfully integrated into interactive environments — in this case, a game.

## 🔍 Features

- 🎮 Classic platformer mechanics: running, jumping, avoiding gaps
- 🧠 Real-time input from OpenEarable sensors
- 🕹️ Sensor-based interaction: **jumping in real life makes the avatar jump**
- 💥 Obstacle collision and failure handling
- ⚙️ Modular design to enable future expansion of sensor-based logic

## 🧪 Context

Developed as part of a university project focusing on **sensor integration and interaction design**. The goal was to move beyond pure data acquisition and demonstrate the **real-time use of wearable sensor data** in an intuitive and engaging application.
